# Wazan 🩺📊

Wazan is an iOS health application designed to help people with diabetes manage and export their glucose data easily using Apple Health.

## 🚀 Features

- 🔗 Secure connection with **Apple Health (HealthKit)**
- 📈 Read blood glucose data automatically
- 📄 Export glucose readings as a **PDF report**
- 💾 Save or share the PDF via Files, AirDrop, or other apps
- ⚙️ Choose glucose units (mg/dL or mmol/L)
- 🔒 Privacy-first: data is accessed only with user permission

## 🧠 Motivation

Many patients struggle with scattered health data and manual tracking.  
Wazan simplifies this by centralizing glucose readings and making them easy to review and share with healthcare providers.

## 🛠 Tech Stack

- **Swift**
- **SwiftUI**
- **HealthKit**
- **UIKit (PDF & Share Sheet)**
- **MVVM Architecture**

## 📱 Requirements

- iOS 16+
- iPhone with Apple Health enabled
- Permission to read Blood Glucose data from Apple Health
